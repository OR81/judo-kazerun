# هیئت جودو شهرستان کازرون

وب‌سایت رسمی هیئت جودو کازرون — ۱۲ صفحهٔ عمومی فارسی/RTL، تابلوی سانس‌های **خانهٔ جودو**،
ثبت‌نام آنلاین با پرداخت اینترنتی، پرتال ورزشکار و مربی، و پنل مدیریت کامل.

هیئت مالک سالن خودش است: صفحهٔ اصلی حول همین بنا ساخته شده — «کدام سانس آزاد است؟»
پیش از هر چیز دیگری پاسخ داده می‌شود.

---

## پشتهٔ فناوری

| لایه | فناوری |
|---|---|
| بک‌اند | Laravel 13 · PHP 8.4 · MySQL 8.4 |
| فرانت‌اند | Blade · Tailwind CSS v4 · وانیلا JavaScript |
| بیلد | Vite 8 (Node.js) |
| احراز هویت | شمارهٔ موبایل + کد پیامکی (بدون رمز عبور) |
| پنل مدیریت | Filament v5 |
| تاریخ شمسی | morilog/jalali |
| تست | Pest 4 · Pint |

**سمت عمومی سایت هیچ فریم‌ورک جاوااسکریپتی ندارد.** Livewire و Alpine فقط داخل باندل
`/admin` بارگذاری می‌شوند و هرگز به صفحات عمومی نمی‌رسند.

## خانهٔ جودو و سانس‌ها

قلب سایت `venues` و `venue_slots` است: هر سالن به سانس‌های هفتگی تقسیم می‌شود و هر سانس
دقیقاً یکی از چهار وضعیت `SlotStatus` را دارد — آزاد برای اجاره، کلاس هیئت، رزرو شده، تعطیل.

**سانس‌های کلاس‌ها دوباره وارد نمی‌شوند.** `VenueSeeder` آن‌ها را از `training_sessions`
موجود می‌سازد و بعد اجاره‌ها را دور آن‌ها می‌چیند؛ هر ردیفی که با سانس دیگری در همان سالن
هم‌پوشانی داشته باشد رد می‌شود. به همین دلیل تابلوی سالن و برنامهٔ تمرینی هرگز نمی‌توانند
با هم اختلاف پیدا کنند (تست `keeps a hall in one state at a time` همین را می‌سنجد).

تابلو هر هفت روز را در HTML رندر می‌کند؛ بدون جاوااسکریپت یک جدول هفتگی معمولی است و
`resources/js/hall.js` آن را به تب تبدیل می‌کند. `day_of_week` مثل `training_sessions`
از صفر (شنبه) شمرده می‌شود.

نرخ اجاره روی خود سالن است و هر سانس می‌تواند نرخ خودش را داشته باشد
(`price` خالی یعنی «نرخ سالن»).

## تصمیم‌های طراحی

### پالت رنگ

سایت **فقط روشن** است. دارک‌مود حذف شده و واریانت `dark:` عمداً به کلاسی گره خورده که هرگز
اعمال نمی‌شود؛ وگرنه واریانت پیش‌فرض Tailwind از `prefers-color-scheme` پیروی می‌کرد و یک
کلاس `dark:` جامانده می‌توانست نیمی از صفحه را برای کاربر دارک‌مود عوض کند.

رنگ برند از خودِ ساختمان می‌آید: آبی، رنگ جودوگی حریف و تاتامی IJF؛ و اُخرا، رنگ کاه تاتامی.
**قرمز و سبز عمداً رنگ برند نیستند** — تابلوی سالن به آن‌ها نیاز دارد تا «رزرو شده» و «آزاد»
معنا بدهند، و برند قرمز این سیگنال را خفه می‌کرد.

Tailwind v4 پالت خود را برای گاموت وسیع بازتنظیم کرده (`blue-700` الان `#1447e6` و
`amber-600` برابر `#e17100`)، پس رمپ‌های `cobalt` و `ochre` با `scripts/brand-scale.mjs`
ساخته می‌شوند: شکل رمپ از Tailwind وام گرفته می‌شود ولی چنان بازهدف‌گذاری می‌شود که
`cobalt-600` دقیقاً `#1D4ED8` و `ochre-500` دقیقاً `#D97706` باشد. خنثی‌ها از خانوادهٔ گرم
`stone` می‌آیند تا در کنار برند سرد، صفحه حس «اتاق» بدهد نه داشبورد.

```bash
npm run brand:scale     # تولید مجدد رمپ‌ها
npm run check:contrast  # بررسی WCAG همهٔ جفت‌رنگ‌ها
```

`check:contrast` اگر هر جفتی زیر حد مجاز بیفتد با کد خطا خارج می‌شود.

### تاریخ و اعداد

همه‌چیز میلادی ذخیره می‌شود و تبدیل فقط در لایهٔ نمایش رخ می‌دهد.

```blade
{{ shamsi($news->published_at) }}            ← ۵ مرداد ۱۴۰۵
{{ shamsi($event->starts_at, 'full') }}      ← یکشنبه ۵ مرداد ۱۴۰۵
{{ fa_number(1250000) }}                     ← ۱٬۲۵۰٬۰۰۰
{{ toman(450000) }}                          ← ۴۵۰٬۰۰۰ تومان
```

> نام تابع `shamsi()` است نه `jdate()` — چون `morilog/jalali` خودش یک `jdate()` سراسری
> تعریف می‌کند و autoload آن بر پکیج ریشه اولویت دارد.

منطقهٔ زمانی روی `Asia/Tehran` تنظیم شده؛ توجه کنید که `config/app.php` پیش‌فرض Laravel
مقدار `UTC` را هاردکد می‌کند و `APP_TIMEZONE` را نمی‌خواند.

### تصاویر

دادهٔ نمونه به سرویس‌های تصویر ریموت اشاره می‌کند (`app/Support/MediaPlaceholder.php`).
`images.unsplash.com` از ایران قابل دسترس نیست، بنابراین از picsum و pravatar استفاده شده است.

پس از آپلود عکس واقعی از پنل مدیریت، همان ستون‌ها مسیر نسبی دیسک را نگه می‌دارند و
`ResolvesMedia` هر دو حالت را می‌شناسد — بدون هیچ تغییری در کد فراخوان.

### ورود

**هیچ رمز عبوری در سامانه نیست** و هیچ ستون `email` یا `password` روی جدول `users` وجود
ندارد. شناسهٔ هر حساب فقط شمارهٔ موبایل است و ورود در دو گام انجام می‌شود: شماره → کد
یک‌بارمصرف پیامکی. **مدیر هم دقیقاً از همین در وارد می‌شود**؛ پنل Filament صفحهٔ ورود
جداگانه ندارد، پس مسیر دومی برای رسیدن به `/admin` وجود ندارد.

- کدها **هش‌شده** ذخیره می‌شوند؛ این جدول تنها انبار اعتبارنامهٔ سامانه است.
- برای هر شماره فقط **آخرین کد** زنده است — «ارسال دوباره» کد قبلی را می‌سوزاند.
- سقف‌ها در `config/sms.php`: اعتبار ۳ دقیقه، ۵ تلاش برای هر کد، فاصلهٔ ۹۰ ثانیه بین
  ارسال‌ها و حداکثر ۵ کد در ساعت برای یک شماره. علاوه بر این، مسیرها throttle دارند.
- شمارهٔ در انتظار تأیید در **سشن** نگه داشته می‌شود نه در فرم، پس گام دوم را نمی‌شود به
  حساب دیگری نشانه گرفت.
- شماره‌ها همیشه به شکل `09xxxxxxxxx` ذخیره می‌شوند (`PhoneNumber::normalize`)، وگرنه
  ردیفی که با `+98…` وارد شده هرگز پیدا نمی‌شد.

```env
SMS_GATEWAY=log             # توسعه: کد در لاگ و روی صفحه
SMS_GATEWAY=kavenegar       # واقعی
KAVENEGAR_API_KEY=...
KAVENEGAR_OTP_TEMPLATE=judo-login
```

> `SMS_EXPOSE_CODES` کد ورود را روی صفحه چاپ می‌کند و **هرگز** نباید در محیط واقعی روشن
> باشد. افزودن درایور تازه یعنی یک کلاس و یک کلید در `config/sms.php` — دقیقاً مثل درگاه پرداخت.

کدهای یک‌بارمصرف پس از یک روز با `model:prune` پاک می‌شوند (زمان‌بندی در `routes/console.php`).

### پرداخت

مبالغ همه‌جا به **تومان** ذخیره می‌شوند. تعویض درگاه فقط با یک کلید در `.env`:

```env
PAYMENT_GATEWAY=fake        # توسعه: صفحهٔ شبیه‌ساز داخل برنامه
PAYMENT_GATEWAY=zarinpal    # واقعی
ZARINPAL_MERCHANT_ID=...
ZARINPAL_SANDBOX=true
```

افزودن زیبال / آیدی‌پی / ملت یعنی یک کلاس درایور جدید و یک کلید در `config/payment.php`.
`verify()` باید idempotent بماند — درگاه‌ها callback را تکرار می‌کنند و کاربر صفحهٔ بازگشت
را رفرش می‌کند.

### دسترس‌پذیری

- کنتراست همهٔ جفت‌رنگ‌ها ماشینی بررسی می‌شود
- حلقهٔ فوکوس دوتکه است: خط اُخرا روی یک کی‌لاین سفید. اُخرا روی سطح برند‌رنگ فقط ۲٫۱:۱ است،
  اما کی‌لاین همان‌جا ۶٫۷:۱ می‌دهد — پس روی هیچ پس‌زمینه‌ای به حلقهٔ دوم نیاز نیست
- وضعیت هر سانس علاوه بر رنگ، آیکون و برچسب متنی هم دارد
- قفل فوکوس در دراور موبایل، جستجو و لایت‌باکس
- تب‌های تابلوی سالن یک `tablist` واقعی با roving tabindex است و فلش‌ها برای RTL آینه شده‌اند
- فلش‌های کیبورد در اسلایدر و لایت‌باکس هم برای RTL آینه شده‌اند
- احترام کامل به `prefers-reduced-motion`
- بدون جاوااسکریپت هم همهٔ محتوا دیده می‌شود، تابلوی سالن هر هفت روز را نشان می‌دهد و فرم
  ثبت‌نام کار می‌کند

## نکات نگهداری

- **ناوبری** در `config/navigation.php` تعریف شده — مگامنو، دراور موبایل و فوتر همگی از
  همان یک منبع می‌خوانند.
- **تنظیمات سایت** (نشانی، تلفن، شبکه‌های اجتماعی، ساعات کاری) در جدول `settings` است و
  با `setting('key')` خوانده می‌شود؛ کل جدول یک‌جا کش می‌شود.
- **`Model::shouldBeStrict()`** در محیط local فعال است و مشکل N+1 را به‌صورت خطا نشان می‌دهد.
- **نقشه**: به‌جای Google Maps یک جای‌گزین ایستا گذاشته شده تا سایت به اسکریپت شخص ثالث
  وابسته نباشد. برای نقشهٔ زنده، بلوک داخل `pages/contact.blade.php` را با نشان یا بلد جایگزین کنید.
- **آیکون‌های برند** (اینستاگرام، تلگرام، واتس‌اپ) SVG درون‌خطی هستند تا وب‌فونت
  ۱۱۳ کیلوبایتی `fa-brands` هرگز بارگذاری نشود.
